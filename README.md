# AMAMB — منصة AMAMB للمعلم والطالب

AMAMB منصة تعليمية متعددة المدارس للمعلمين والطلاب والمدراء: حضور عبر QR، دفتر درجات كامل، سلوك، واجبات، لوحة صدارة، تقارير قابلة للطباعة وواتساب، خطط تدخل وإثراء، شهادات — بالإضافة إلى **أدوات كيمياء تفاعلية، بنك أسئلة بثمانية أنواع، اختبارات إلكترونية تُصحَّح تلقائياً، ونظام صلاحيات ومراسلة وسجل أنشطة**.

- **اللغة:** العربية (افتراضياً، RTL كامل) أو الإنجليزية (LTR) بضغطة زر
- **الواجهة:** HTML/CSS/JS خالص بدون build أو frameworks — انشر أي static host واشتغل
- **الخلفية:** Supabase (PostgreSQL + PostgREST)
- **التقييم:** معيار AMAMB من 100 نقطة (أكاديمي 90 + غير أكاديمي 10) وسلّم تقديرات A+ إلى F

## حساب الدخول

المنصة تعمل بحساب حقيقي مملوك لصاحب المنصة (لا توجد حسابات تجريبية).
الدخول: **بريد أو هاتف + كلمة مرور** — وبدون أي خطوة تحقق إضافية.
إدارة الحسابات والصلاحيات: من صفحتي «التحكم بالصلاحيات» و«سجل الأنشطة» داخل لوحة الإدارة.

## ماذا تدير من لوحة الإدارة؟

- **المناهج والوحدات:** إنشاء/تفعيل/إيقاف مناهج (كيمياء ٣ ثانوي مثلاً) ووحداتها.
- **الدروس:** إنشاء/تعديل/حذف دروس، ربط فيديو يوتيوب، وإرفاق وظائف وأنشطة بكل درس.
- **بنك الأسئلة:** ٨ أنواع (اختيار من متعدد، متعدد، صح/خطأ، أكمل الفراغ، إجابة قصيرة، ترتيب خطوات، توصيل، مقالي) مع صعوبة (١–٣)، تصنيف بالمنهج/الوحدة، ودرجة لكل سؤال.
- **الاختبارات:** بانٍ اختبارات (مدة زمنية، عدد محاولات، تفعيل)، ربط أسئلة من البنك، صحّ تلقائي للأسئلة الموضوعية، وتصحيح يدوي للمقالي من «النتائج»، وسجل محاولات لكل طالب.
- **الشعب والقوائم:** إنشاء/تعديل/حذف شعب، إضافة/إخراج/نقل الطلاب بين الشعب، وربط معلمين بالشعب.
- **الطلاب والمعلمون:** إنشاء/تعديل/حذف حسابات، إنشاء حساب دخول لأي طالب، إعادة تعيين كلمات المرور، تغيير الأقسام بنقرة.
- **الكيمياء:** جدول دوري تفاعلي (CRUD كامل للعناصر)، ثوابت وقيم تجريبية قابلة للتحرير، معادلات كيميائية مع **أداة موازنة المعادلات** (تتحقق من الذرات تلقائياً).
- **الرسائل:** مراسلة الجميع / المعلمين / الطلاب / شعبة بعينها / شخص محدد — مع **إيصالات قراءة** وحذف.
- **التحكم بالصلاحيات:** ترقية/إنزال أي حساب (مدير ↔ معلم ↔ طالب)، قبول الحسابات المعلّقة وتعليقها، وحماية آخر مدير نشط.
- **سجل الأنشطة:** من أنشأ/عدّل/حذف/فعّل ماذا ومتى (مع الفاعل والوقت والتفاصيل).

## ماذا يرى المعلم والطالب؟

- **المعلم:** كل أدواته السابقة + صفحة «نسبة النجاح ونقاط الضعف» (نسبة النجاح ≥٦٠٪ لكل عنصر تقييم، الطلاب دون المعدل، إحصائيات حضور لكل طالب) + الكيمياء (للعرض والموازنة) + الرسائل.
- **الطالب:** لوحته السابقة + صفحة «الاختبارات» (يحل الاختبارات المفعّلة بمؤقّت، ويُصحَّح تلقائياً وتظهر نتيجته) + الكيمياء + الرسائل.

## النشر (Static)

المنصة ملفات ثابتة — ارفعها كما هي على أي استضافة ثابتة (GitHub Pages, Netlify, Vercel, Cloudflare Pages) وافتح `index.html`. الموقع المرجعي يعمل على GitHub Pages من الفرع `main`.

### Render (Static Site)

المشروع يحتوي على `render.yaml` جاهز للنشر على Render كموقع ثابت:

1. من Render: **New + → Blueprint** (أو Static Site) واربط الريبو `MrMohamedAbdelmoaty/amamb`.
2. اختار `render.yaml` / أو إعدادات: Build Command: `echo "AMAMB is a static site — no build step"` و Publish Directory: `.`
3. اضغط Deploy — هتاخد دومين مجاني `amamb.onrender.com` (أو أي اسم تختاره) + HTTPS تلقائي، والنشر التالي بيتم تلقائياً مع كل push على `main`.
   - أو مباشرة من الزر: https://render.com/deploy?repo=https://github.com/MrMohamedAbdelmoaty/amamb

لا تحتاج أي متغيرات بيئة: الواجهة بتكلم Supabase مباشرة، و`js/config.js` فيه anon key العام فقط (مسموح يكون ظاهر للعلن في تطبيقات Supabase). لا تحط service role key في أي ملف واجهة.

## إعادة بناء قاعدة البيانات

`sql/schema.sql` — نسخة مرجعية من المخطط الكامل (الجدول الأصلي + إضافات v2: المناهج، الوحدات، الدروس، المرفقات، الأسئلة، الاختبارات، محاولات الاختبار، الكيمياء، الرسائل، سجل الأنشطة، وعمود حالة الحساب). لا تتضمن حسابات ديمو — أنشئ مديرك الحقيقي بتعليمات الملف.

## أمان

- مفتاح Supabase في `js/config.js` هو الـ **anon key** العام — مصرح له بأن يكون علنياً في تطبيقات Supabase.
- مقارنة كلمة المرور تتم داخل قاعدة البيانات (PostgREST equality filter على SHA-256) ولا تصل للمتصفح أي أسرار إدارية؛ والدخول محكوم بحالة الحساب (pending يُمنع من الدخول).
- يُنصح مستقبلاً بنقل تحقق كلمة المرور إلى Edge Function وسحب صلاحية القراءة المباشرة لعمود `password_hash` من دور anon.
