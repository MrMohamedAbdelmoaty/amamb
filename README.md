# AMAMB — منصة AMAMB للمعلم والطالب

AMAMB هو منصة تعليمية متعددة المدارس للمعلمين والطلاب والمدراء: حضور عبر QR، دفتر درجات كامل، سلوك، واجبات، لوحة الصدارة، تقارير قابلة للطباعة، خطط تدخل وإثراء، وشهادات.

- **اللغة:** العربية (افتراضياً، RTL كامل) أو الإنجليزية (LTR) بضغطة زر
- **الواجهة:** HTML/CSS/JS خالص بدون أي build أو frameworks — انشر أي static host واشتغل
- **الخلفية:** Supabase (PostgreSQL + PostgREST + Edge Function للمصادقة)
- **التقييم:** معيار AMAMB من 100 نقطة (أكاديمي 90 + غير أكاديمي 10) وسلّم تقديرات A+ إلى F

## حساب الدخول والتحقق

المنصة تعمل بحساب حقيقي مملوك لصاحب المنصة (لا توجد حسابات تجريبية).
تسجيل الدخول: بريد أو هاتف + كلمة مرور، ثم **رمز تحقق يُرسل إلى البريد** في كل عملية دخول.
الصلاحيات وإدارة الحسابات: من صفحة «المعلمون» داخل لوحة الإدارة.

## النشر (Static)

المنصة عبارة عن ملفات ثابتة — ارفعها كما هي على أي خدمة استضافة ثابتة (GitHub Pages, Netlify, Vercel, Cloudflare Pages) وافتح `index.html`.

## إعادة بناء قاعدة البيانات

راجع `sql/schema.sql` — نسخة مرجعية من المخطط + بيانات الديمو.

## أمان

- مفتاح Supabase الموجود في `js/config.js` هو الـ **anon key** العام — مصرح له بأن يكون علنياً في أي تطبيق Supabase.
- تسجيل الدخول يتم عبر Edge Function (`amamb-login`): كلمة المرور تُقارن داخل السيرفر ولا يصل للمتصفح عمود الهاش.
- هذا ديمو — لا تخزّن فيه أي بيانات شخصية حقيقية.
